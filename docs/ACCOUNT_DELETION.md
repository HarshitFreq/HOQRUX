# ACCOUNT & DATA DELETION // HOQRUX

**Last updated:** November 21, 2026  
**Application:** HOQRUX  
**Developer Contact:** `privacy@hoqrux.app`  

In compliance with the **Google Play User Data Policy**, HOQRUX provides all users with clear, frictionless mechanisms to delete their accounts and permanently erase all associated data.

---

## 1. What Data Is Deleted Upon Request

When an account deletion request is processed, the following information is permanently purged:
* **Account Identity:** Email address, username, authentication identifiers, and password hash.
* **Tracking Records:** All media tracking entries, marked films, watched episodes, and watch progression.
* **Watchlists & Curation:** Custom lists and title associations.
* **Viewing Logbook:** All viewing history entries and historical timestamps.
* **Cloud Database Rows:** All entries tied to your User ID in the `user_tracking` cloud database.

---

## 2. In-App Deletion (Immediate)

If you have the HOQRUX application installed:
1. Open the **HOQRUX** app.
2. Navigate to the **PROFILE** tab.
3. Select the **ABOUT & DATA** section.
4. Scroll to **DATA PURGE // DANGER ZONE**.
5. Tap **DELETE ACCOUNT & PURGE ALL DATA**.
6. Confirm the prompt. All records will be immediately erased from cloud servers and local device storage.

---

## 3. Web / Email Deletion Request (Without App Installed)

If you have uninstalled the application or cannot access your device, you can request account deletion online:

1. Send an email to **`privacy@hoqrux.app`** with the subject line:  
   `DATA DELETION REQUEST: [Your Registered Email]`
2. State your registered email address and request the complete deletion of your account.
3. We will send a confirmation link to that email address to verify account ownership.
4. Once verified, all associated data will be permanently and irrevocably deleted from our database within **48 hours**.
