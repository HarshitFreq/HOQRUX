## 5. EAS Build & Release Execution

To generate the signed **Android App Bundle (`.aab`)** ready for direct upload to Google Play Console:

1. **Install EAS CLI:**
   ```bash
   npm install -g eas-cli
   # or run directly with npx
   npx eas-cli@latest login
   ```

2. **Configure Cloud Signing (First Time):**
   ```bash
   npx eas-cli@latest credentials
   ```

3. **Build Android App Bundle (`.aab`):**
   ```bash
   npx eas-cli@latest build -p android --profile production
   ```

4. **Upload to Google Play Console:**
   * Go to [Google Play Console](https://play.google.com/console).
   * Create app: **HOQRUX** (Free, App, No Ads).
   * Navigate to **Testing** → **Internal testing** (or **Production**).
   * Create new release and upload the `.aab` generated by EAS.
